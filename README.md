# قنوات

تطبيق سطح مكتب بسيط لعرض قوائم IPTV (ملفات M3U/M3U8) عبر متصفحك.
الخادم بلغة بايثون (مكتبة قياسية فقط) والواجهة HTML/JS.

## التشغيل

يحتاج Python 3.9 أو أحدث.

```bash
python server.py --playlist sample.m3u
```

أو من رابط مباشر:

```bash
python server.py --playlist https://example.com/list.m3u
```

سيفتح المتصفح تلقائياً على عنوان محلي مثل `http://127.0.0.1:52348/`.

### الخيارات

- `--playlist` **(إجباري)**: مسار ملف أو رابط لقائمة M3U.
- `--port` منفذ محدد (الافتراضي: منفذ متاح عشوائي).
- `--no-browser` لا يفتح المتصفح تلقائياً.

## الاختبارات

```bash
python -m unittest discover -s tests -v
```

## الملفات

- `server.py` نقطة التشغيل: يقرأ القائمة، يرفع خادم HTTP محلي، ويفتح المتصفح.
- `m3u.py` محلّل بسيط لملفات M3U (اسم، شعار، تصنيف، رابط).
- `static/` واجهة الاستخدام (HTML + CSS + JavaScript).
- `sample.m3u` قائمة قنوات تجريبية عامة لاختبار المشغّل.
- `tests/test_m3u.py` اختبارات وحدة للمحلّل.

## ملاحظات

- التشغيل محلي بالكامل؛ لا يُرسل شيء لأي خادم بعيد غير روابط البث نفسها.
- تشغيل HLS يعتمد على مكتبة `hls.js` تُحمَّل من CDN‏ (`cdn.jsdelivr.net`).
- جودة البث واستقراره يعتمدان على مصدر القائمة.
- تأكّد من امتلاكك الحق القانوني في بث القنوات التي تضيفها.
